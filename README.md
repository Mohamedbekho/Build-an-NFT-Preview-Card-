### What I learned

Working on this project helped me practice and solidify several key frontend concepts:
- Using **Flexbox** (`justify-content: space-between`) to align price and time details cleanly across opposite sides of the card.
- Implementing an image hover overlay using **absolute positioning** and a smooth opacity transition.
- Managing responsive design cleanly using relative units and media queries for smaller devices.
